# 字幕、镜头与素材关联

## 使用

先导入或识别字幕。从字幕面板的动效匹配入口，或顶部「AI 视频编排」打开统一对话框。选中字幕时仅编排所选段落，否则编排全部字幕。顶部入口在没有字幕时仍打开独立 Shotcraft 图片编排，便于制作不依赖口播的产品短片。

- 自动混合：AI 按同一组字幕的内容决定主叙事 A-roll 或补充画面 B-roll，并共同选择动效和素材。
- 纯 A-roll：保留时间线上持续覆盖该段的主叙事视频，只允许适合口播的动效；缺少主叙事视频时明确报错。可在视频属性中指定素材角色；没有显式角色时，已放置且关联识别字幕的视频可推定为 A-roll。
- 纯 B-roll：使用相关全屏补充视频或带完整底色的 Shotcraft 图片/图形/字卡镜头持续覆盖画面，保留原口播音轨，补充视频静音。透明卡片需要全屏补充视频承托，不能仅凭“适用 B-roll”就算覆盖口播。不会删除或静音原口播。

分镜要求示例：`0-5秒 A-roll 保留口播；5-12秒 B-roll 用产品截图解释痛点；12-20秒 B-roll 用前后对比展示修改结果。重点词与字幕一致。`

在同一对话框选择参与匹配的图片和视频、背景音乐、音乐源起点与音量，并决定是否启用图片识别、音乐卡点和动作音效。点击「生成整套分镜」只生成预览清单，不改变工程；检查每段角色、时间和镜头后，再点击「应用整套编排」。

支持 `5-12秒 B-roll`、`00:05–00:12 Broll` 格式的角色时间段。时间是工程绝对时间；按每条字幕中点决定归属，切换对齐字幕边界，不保证任意非字幕边界的毫秒级切换。倒序、重叠、超出工程及纯模式冲突会报错。具体镜头名称、用途及其它自然语言要求由 AI 理解，不是固定命令语言。

## 数据链路

第一阶段读取字幕原文与时间、所选素材名称/尺寸/角色/关联字幕摘要、所选图片缩略图，以及已有视频和镜头的时间、文案与绑定素材名称，输出连续语义段、A-roll/B-roll 角色、动效和选型理由。第二阶段只能在同一字幕段与已选动效内安排文字、素材槽、关键词、转场、动作音效及卡内节奏。目录中的已适配且不依赖人工焦点的 Shotcraft 可作为 B-roll 唯一全屏主动效，其他动效仍使用已有字幕时间锚点能力。

客户端校验角色和时间要求、A-roll 素材覆盖、动效适用范围、B-roll 完整画面、图槽类型及数量、文案字段、强调词、动作事件和全屏冲击预算。音乐只在本地解码和分析，发给模型的是 BPM、拍点数量和强瞬态相对时间，不上传音乐文件。字幕组首尾保持不动；Shotcraft 通过同一个序列编译器得到完整动作时钟、停留和转场，并把已验证的内部动作就近对齐拍点。普通动效的必要音效以字幕动作起点为锚，也会在 200 毫秒窗口内贴近拍点。

写入工程的镜头沿用 `sourceSubtitleId`、`sceneGroupId`、`matchQuery`、`bindings` 和现有 `shotcraft`，预览与导出共用这些数据，无需升级 schema 32。重新匹配会更新已关联的可编辑动效；锁定的动效、B-roll 或音效保留且不重复插入。视觉、动作音效和本次背景音乐在同一次提交中应用，可一次撤销/重做。匹配记录保存角色、字幕索引及动效，可展开查看关联。

## 边界与验证

开启图片识别时，最多 12 张所选图片会缩到最长边 960 像素并随字幕请求发送给已配置的模型；视频文件、工程文件和音乐文件不会上传。关闭图片识别时仅发送素材元数据及关联字幕摘要。模型仍可能误读图片或选错语义素材，应用前必须检查分镜。已有镜头作为内容上下文传给 AI，并不自动转换成可双向同步的分镜计划；手动改字幕后需要重新生成。

纯模式约束生成结果，不会删除用户已有的无关联画面；时间线上已有不相关的全屏镜头可能仍遮挡，需在应用结果后检查。任意截图焦点、尚未通用适配的固定示例卡、自动视频画面内容理解不在本轮范围内。音效面板的独立匹配仍作为局部工具，不会自动重做整套分镜；原动效匹配能力已作为统一入口的视觉选型引擎继续使用。

统一入口新增了结构化响应、时间/角色校验、图片识别、预览后应用、Shotcraft 字幕关联、转场、动作音效、音乐卡点及单次撤销重做测试。当前统一入口只完成本地测试和模拟结构化响应验证，尚未追加新的真实云端调用。50 秒样片的真实云端响应来自先前已授权的图片编排测试，最终视频含明确记录的本地审片修订。
