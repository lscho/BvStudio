# 字幕、镜头与素材关联

## 使用

先导入或识别字幕。从字幕面板的动效匹配入口，或「AI 镜头编排 → 按现有字幕编排 A-roll / B-roll」打开共用对话框。选中字幕时仅编排所选段落，否则编排全部字幕。

- 自动混合：AI 按同一组字幕的内容决定主叙事 A-roll 或补充画面 B-roll，并共同选择动效和素材。
- 纯 A-roll：保留时间线上持续覆盖该段的主叙事视频，只允许适合口播的动效；缺少主叙事视频时明确报错。可在视频属性中指定素材角色；没有显式角色时，已放置且关联识别字幕的视频可推定为 A-roll。
- 纯 B-roll：使用相关全屏补充视频或带完整底色的 Shotcraft 图片/图形/字卡镜头持续覆盖画面，保留原口播音轨，补充视频静音。透明卡片需要全屏补充视频承托，不能仅凭“适用 B-roll”就算覆盖口播。不会删除或静音原口播。

分镜要求示例：`0-5秒 A-roll 保留口播；5-12秒 B-roll 用产品截图解释痛点；12-20秒 B-roll 用前后对比展示修改结果。重点词与字幕一致。`

支持 `5-12秒 B-roll`、`00:05–00:12 Broll` 格式的角色时间段。时间是工程绝对时间；按每条字幕中点决定归属，切换对齐字幕边界，不保证任意非字幕边界的毫秒级切换。倒序、重叠、超出工程及纯模式冲突会报错。具体镜头名称、用途及其它自然语言要求由 AI 理解，不是固定命令语言。

## 数据链路

第一阶段读取字幕原文与时间、素材名称/尺寸/角色/关联字幕摘要，以及已有视频和镜头的时间、文案与绑定素材名称，输出连续语义段、A-roll/B-roll 角色、动效和选型理由。第二阶段只能在同一字幕段与已选动效内安排文字、素材槽、关键词及卡内节奏。目录中的已适配且不依赖人工焦点的 Shotcraft 可作为 B-roll 唯一全屏主动效，其他动效仍使用已有字幕时间锚点能力。

客户端校验角色和时间要求、A-roll 素材覆盖、动效适用范围、B-roll 完整画面、图槽类型及数量、文案字段、强调词和全屏冲击预算。Shotcraft 通过同一个序列编译器得到完整动作时钟和停留，按字幕组首尾落位，不按背景音乐移动字幕边界。原配音、背景音乐及音效编排入口继续独立工作。

写入工程的镜头沿用 `sourceSubtitleId`、`sceneGroupId`、`matchQuery`、`bindings` 和现有 `shotcraft`，预览与导出共用这些数据，无需升级 schema 32。重新匹配会更新已关联的可编辑动效；锁定的动效或 B-roll 保留且不重复插入。一次匹配支持撤销/重做。匹配记录保存角色、字幕索引及动效，可展开查看关联。

## 边界与验证

该入口目前读取素材元数据及字幕摘要，不上传图片或视频做视觉识别；素材名称应描述真实内容，关联是否恰当仍需要审片。图片编排入口继续支持已有图片识别。已有镜头作为内容上下文传给 AI，并不自动转换成同一份可双向同步的分镜计划；手动改字幕后，需要重新匹配，不能宣称画面内容已经自动重写。

纯模式约束生成结果，不会删除用户已有的无关联画面；时间线上已有不相关的全屏镜头可能仍遮挡，需在应用结果后检查。任意截图焦点、尚未通用适配的固定示例卡、自动视频内容理解不在本轮范围内。

本轮新增了本地结构化响应、时间/角色校验、分镜入口交互、Shotcraft 字幕关联导出计划及撤销重做、锁定 B-roll 重匹配回归测试；新关联入口未追加真实云端调用。50 秒样片的真实云端响应来自先前已授权的图片编排测试，最终视频含明确记录的本地审片修订。
