# AI 生成与动效匹配

覆盖云端模型配置、AI 文案与口播生成、两阶段动效匹配、匹配历史与偏好，以及 API Key 的存放边界。语音合成与识别见 [`07-云端语音.md`](07-云端语音.md)，布局解析规则见 [`06-AI动效布局解析.md`](06-AI动效布局解析.md)，字幕/镜头/素材关联见 [`04-字幕镜头与素材关联.md`](04-字幕镜头与素材关联.md)，Shotcraft 编排见 [`03-Shotcraft镜头.md`](03-Shotcraft镜头.md)。

## 统一 AI 视频编排

已有字幕时，从字幕「匹配动效」或顶部「AI 视频编排」进入，支持自动混合、纯 A-roll、纯 B-roll 和带工程时间的分镜要求（如 `0-5秒 A-roll；5-12秒 B-roll 用产品截图对比`）。两阶段共用字幕、所选素材、图片识别结果、已有镜头和本地音乐节奏摘要；同一个语义段一次生成现有动效、Shotcraft 镜头、素材绑定、字幕重点词、转场和动作音效。生成结果先展示分镜清单，确认后以一次撤销操作写入视觉、音效和背景音乐。

「Shotcraft 文案」可在编排前选择两种策略。默认「口播字幕优先」保留时间线字幕，Shotcraft 只从不依赖自带设计文案的镜头中选型，不再增加底部镜头说明；无合适镜头时使用其它素材动效或动态图形背景。「宣传片文案」允许 Shotcraft 模板内文案或全屏镜头说明承担文字，并在 Shotcraft 覆盖区间隐藏重叠的时间线字幕，区间外字幕不受影响。两种策略都保持镜头内容铺满画布，预览和导出使用同一规则。

字幕边界不会为了卡点移动；Shotcraft 内部动作和普通动效音效会就近贴合真实拍点。纯 A-roll 需要已放入口播视频，纯 B-roll 保留原口播。只有图片素材时，客户端会为每个 B-roll 语义段确定性补充「静态图运镜」全屏基础画面，使用同图模糊铺底、主体完整显示和克制推近；没有任何图片或补充视频时，Pro 的纯 B-roll 会在 3–30 秒语义段优先使用当前身份可用、无需素材的全屏 Shotcraft，Free 或不适合 Shotcraft 的短长段落继续轮换网格、点阵、等高线或斜纹等全屏动态图形背景。自动混合模式中的 B-roll 使用 Shotcraft 作为全屏底层时，信息段必须叠加恰好一张无素材的信息卡；只有 intent=ambient/transition 且 evidenceKinds 为空或仅 none 的纯氛围/纯转场段可省略；卡片只提炼该语义段字幕明确给出的数字、对比、步骤或结论，没有明确数字时不得推断数值。纯 A-roll 与纯 B-roll 不开放该叠层例外。普通透明卡片只能作为叠加内容，不能单独承担基础画面。图片识别只发送所选图片的缩略图，音乐文件不上传；需人工圈焦点的镜头继续使用独立图片编排入口。详见 [`04-字幕镜头与素材关联.md`](04-字幕镜头与素材关联.md)。

`info-board` 可同时承担普通论点板和证据信息板：仅使用标题、清单、术语、公式或结论行时不要求来源；加入数据、引用、截图、计数、占比或趋势等证据行时，必须通过 `note|来源：…` 写明真实出处。无法确认来源时，AI 应退回普通论点行或非证据动效，不得编造来源。

第一阶段的 `evidenceKinds` 使用固定协议枚举；兼容模型偶发返回的中英文常见别名，客户端会在严格校验前映射为标准值，无法识别的非关键说明降级为 `none`，不会因此中断整套分镜。

带素材槽的动效只能作为场景主动效。第一阶段若误把截图、视频或图片槽动效放进辅助层，客户端会在进入素材绑定阶段前移除该非法辅助项；无可用视觉素材的纯 B-roll 由当前身份可用的全屏 Shotcraft 或动态图形背景承载，不会生成无法绑定的素材占位。

## 两条创作链路

两条创作链路最终共用同一个动效匹配入口：

- 口播视频链路：视频 → 本地提取音频 → 云端 ASR 时间字幕 → AI 语义选型 → 素材与时间线编排；
- 无视频链路：AI 文案与口播 → 时间字幕 → AI 语义选型 → 素材与时间线编排。

请求会携带字幕绝对时间、opening / middle / ending 阶段，以及导入视频的角色提示、尺寸、时长和关联字幕摘要。第一阶段接收完整动效名称、简介与匹配知识；第二阶段保留素材槽、卡内参数和时间锚点，不以精简字段牺牲匹配能力。模型结构或语义计划首次校验失败时，客户端会附带精简错误自动请求修正一次，并累计两次请求的 Token 用量。

模型返回的高亮关键词必须来自字幕原文；客户端最终最多保留 2 个、每个 2–8 个字符，并把总高亮控制在字幕有效字符的约 40% 以内，四字以内短字幕不自动高亮。AI 未返回关键词时，本地只补充 1 个核心词，不再按分句补满。动效文案可以概括但不得虚构数字或事实；图表结果还会与整组字幕事实二次核对。模型坐标只作为布局建议，客户端根据最终画布比例、图层有效时间和安全区进行确定性碰撞解析。人物避让框支持拖动、缩放、方向键微调、撤销和重做，播放、动效预览与导出时自动隐藏。云端文案和动效匹配使用 SSE 流式接收，界面持续显示连接、接收、自动修正与校验状态；取消或流中断时不会把不完整结果写入工程。

## AI 内容插入与两阶段匹配规则

AI 内容支持顺序插入、替换区间和叠加区间；内容生成只写入文案、口播与时间字幕，用户随后可独立调用两阶段动效匹配。

第一阶段把字幕连续覆盖为通常 10–30 秒、每段一个论点的语义段，0–5 秒强制建立钩子，并从完整自动动效目录中按用途、触发条件、证据形态、层级和素材需求选型；第二阶段只在已选卡中分配工程素材、证据来源、短文案、运镜、位置与字幕节奏锚点。超过 80 条字幕时会在停顿或句末边界自动分批并映射回全局索引，不丢字幕。缺少图片或录屏时仍插入真实动效片段并显示半透明“待补素材”占位，不使用示例图或虚构路径。

全部逐项、逐词、多阶段、计数、滚动和动作剧本时间参数由客户端根据字幕真实时间计算；全屏底层从段首字幕开始并保持到段末，自动混合中的 Shotcraft 信息卡从对应事实首次出现的字幕进入并保持到段末，允许与底层在同一字幕边界同步进入；普通两张内容卡仍须至少错开 0.5 秒。应用编排与工程检查使用相同的叠卡例外：同一 AI 场景组恰有一个 Shotcraft 底层和一张合规信息卡，且底层完整覆盖卡片区间时，允许同步进场；第三层、非法搭配和普通双卡仍保留原校验。模型漏填普通卡片的节奏锚点时，客户端优先用卡片文案在段内真实字幕中的匹配位置补齐；没有可匹配文字或只有单条字幕时使用该卡进场字幕的真实边界，并由既有时长编译器分配卡内节奏，不假称拥有逐词时间。模型已填写的越界锚点不会被覆盖，仍触发修正。Shotcraft、素材展示动效和背景音乐都精确覆盖所选字幕区间。整套字幕重新编排时会移除旧的未锁定 AI 视觉与音乐尾部片段，锁定片段仍保留。第一阶段选中的每张卡必须在段内恰好落盘一次；自动混合中需要叠卡的 Shotcraft 段落，在底层回退替换后、第二阶段生成后和最终规范化后分别校验信息卡；缺卡、缺文案或被去重丢卡都要求模型修正，不静默退化成单层。底层替换优先保留已选辅助卡，卡片内容与参数由模型依据字幕生成。第一阶段为每个候选标记 shotcraftOverlayEligible，并单列按当前身份过滤的 Shotcraft 叠加卡白名单；选错辅助卡时，修正请求指出具体 ID、素材/分类/适用范围/层级原因及可用 ID，不再把卡片不合规误报为未选择自动混合模式。其它段落的第二阶段偶发漏掉普通结构化卡片时，客户端会直接从该语义段字幕恢复文案并补回时间线，反转卡只在字幕明确包含“不是…而是…”或“从…转向…”关系时恢复，不能安全恢复的 Shotcraft、图表、证据卡和素材卡仍交给模型修正。同段强调色统一，同场景最多累积 2 个内容层。无字幕数据依据的图表会触发 AI 自动修正，最终不会被静默替换成未选中的简单卡。导入视频的现有角色和关联字幕摘要会参与 A-roll/B-roll 判断，写入前由本地预检阻止分段空洞、相邻同 kind、非法独占叠层、双背景、越界锚点、缺失选型、重复状态及无来源证据；唯一允许的独占叠层是自动混合 B-roll 的 Shotcraft 底层与一张合规信息卡。布局解析器继续避开底部字幕、章节进度和已有动效，规则见 [`06-AI动效布局解析.md`](06-AI动效布局解析.md)。

## 匹配入口与范围

「匹配」分别位于动效和音效 Tab 底部；字幕 Tab 底部保留生成与配音。

动效匹配不添加音效，也不清除已有音效；音效匹配只更新所选字幕对应的音效轨内容，无字幕选区时匹配全部字幕（单次最多 80 条），保留锁定音效和未选范围。独立 AI 音效匹配、普通动效的场景音效和 Shotcraft 镜头动作音效统一从资源面板的新版音效库选择；连续场景最多一个独立匹配音效，且相邻音效至少间隔 2.5 秒。客户端只把当前 Free/Pro 身份可用且允许自动选择的音效发送给模型，并在写入时间线前再次校验权限。旧版 9 个合成立体声 WAV 不再参与新生成或匹配，仅在打开已使用它们的旧工程时保留恢复兼容。分类与免费额度见 [`13-音效分类与Pro可用性约束.md`](13-音效分类与Pro可用性约束.md)。

## 匹配历史与偏好

动效 Tab 底部的历史按钮可查看匹配记录，对比 AI 初选与之后的删除、替换、时长、位置、大小、素材和层数变化。记录不包含素材路径或预览 URL，只有用户点击“采纳为偏好”后才会作为后续选型、时长和位置的软参考，当前字幕证据、素材槽、安全区与互斥规则始终优先。

## 云端模型配置

OpenAI Responses、OpenAI Chat Completions 兼容协议和 Anthropic Messages；内容生成由模型服务决定输出上限，并支持连接测试、模型列表、请求取消、指数退避重试和会话 Token/费用估算。文本大模型在“客户端设置 → 云端模型”分组中配置，可继续使用 DeepSeek 等 OpenAI 兼容服务；语音模型单独配置，见 [`07-云端语音.md`](07-云端语音.md)。

## 凭证与安全

API Key 只通过既有安全路径处理：桌面端写入应用数据目录下权限受限的凭证文件（`<app_data_dir>/credentials`，目录权限 0700，见 `src-tauri/src/secrets.rs`），浏览器开发预览最多使用会话级存储。不得写日志、localStorage、工程 JSON 或错误详情。模型返回结果通过本地 JSON Schema 校验；外部输入不可信，继续通过 Zod schema 校验后再进入领域模型。详见 [`AGENTS.md`](../AGENTS.md) 与 [`10-应用运行时与平台集成.md`](10-应用运行时与平台集成.md)。

## 自动修复与验证边界

Shotcraft 自动修复会反馈具体镜头、文案字段、区域和动作事件，并校验重复选型；约 50 秒的真实云端实测记录与内容审查边界见 [`03-Shotcraft镜头.md`](03-Shotcraft镜头.md#本轮验证)。
