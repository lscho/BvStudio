# 文档索引

面向人和 Agent 的文档地图。根 [`README.md`](../README.md) 是项目入口，[`AGENTS.md`](../AGENTS.md) 是开发约束，[`DESIGN.md`](../DESIGN.md) 是视觉规范。本目录只放产品行为、格式与协议文档。

## 命名规范

- 主题文档统一命名为 `NN-中文标题.md`：两位序号 + 连字符 + 中文标题，标题内不加空格。
- 序号即推荐阅读与维护顺序，按「产品能力 → 约束与格式 → 服务与运维」分段；新增文档统一追加到末尾，不在中间插号（避免批量改引用）。
- 例外：本索引固定为 `README.md`（GitHub 会把它渲染成目录落地页）；`licenses/` 下的第三方许可证保留上游原始文件名；`shotcraft-migration.json` 是数据文件而非文档。
- 文档之间一律用相对链接（本目录内直接写文件名，跨目录写 `../` 或 `docs/` 前缀）。
