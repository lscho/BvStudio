# Shotcraft 镜头 · 首轮

六种镜头按 video-shotcraft 的准确 demo 时序适配为 BVideo 的 React 组件。无需安装 Remotion 或启动外部工作台。镜头、素材、焦点与转场保存在工程中，预览和成片导出消费同一组件及微秒时钟。

## 使用

1. 在「动效」搜索 `Shotcraft`，添加镜头；也可在「展示」分组找到它们。
2. 在属性中绑定图片。支持已有素材、导入和拖入，卡片槽支持排序。
3. 柔焦标题、前后对比、空间步进可改文案；用 `｜` 分隔行或步骤，标题可用空格指定分词。
4. 焦点巡览有四个焦点，聚光悬浮卡有一个主角区域。点击截图移动焦点，或输入相对原图的左侧、顶部、宽度、高度百分比。横竖画幅会换算图片实际显示区域，留黑不计入原图坐标。
5. 「额外停留」在阅读阶段增加静止时间，不拉长进场、相机飞行和归位动作。「播放时长」则调整整个镜头的速度。时间输入失焦或回车提交，支持撤销、重做。
6. 接好同轨的上一镜头后，在后一镜头的「衔接上一镜头」选择「流白」或「整屏上推」。改变片段时长后，可用时间输入重新对齐下一镜头。

| 镜头 | 图片要求 | 原始动作 / 默认时长 | 额外停留位置 |
| --- | --- | --- | --- |
| 柔焦标题 | 无 | 逐词上浮、透明度与模糊同进度；114 帧 / 3.8 秒 | 字幕落稳后 |
| 前后对比 | 处理前、处理后各 1 张 | 快甩、回弹、停留、慢扫；150 帧 / 5 秒 | 慢扫完成后 |
| 焦点巡览 | 页面截图 1 张 | 四次焦点飞行与光标同步；180 帧 / 6 秒 | 最后焦点落稳后 |
| 空间步进 | 按顺序 3 张 | 三个空间姿态依次转正，最后总览；180 帧 / 6 秒 | 总览落稳后 |
| 聚光悬浮卡 | 页面 1 张，可选高清主角 1 张 | 聚光、侧斜推进、抬升、两圈轮廓光、归位；145 帧 / 约 4.83 秒 | 悬浮末段、归位之前 |
| 叠卡扇展 | 2–8 张 | 错峰弹入、统一扇展；126 帧 / 4.2 秒 | 展开落稳后 |

帧号以参考实现的 30 fps 为准，导出支持项目帧率。停留与转场随整段变速；属性面板显示变速后的秒数。首轮只接受静态图片；建议使用足够清晰的截图，并让高清主角与所选区域保持相同比例。悬浮时原位由「主角原位底色」填补，应选择接近页面的底色。

## 转场与编辑边界

转场占用后一镜头的开头：上一镜头的末态作为完整画面冻结，后一镜头在自己的时钟上开始运行。上推同时移动两张整屏画面；流白沿参考包络覆盖切换点。此轮不实现两段视频同时播放的重叠转场。

两段必须是同轨、可见、紧邻的 Shotcraft 镜头，且整体变换为居中、缩放 1、旋转 0、不透明度 1，没有整体位置关键帧或提前弱化。移动、删除或变换使关系失效时自动退回直接切换，属性中给出提示；不会错误复用其他片段。拆分后一段保留源时钟；拆分前一段时更新末段引用；复制整组时引用复制后的片段。锁定轨道和锁定片段沿用编辑器的保护规则。

增加停留只改变所选片段，不自动移动其他片段。裁掉停留阶段后的片段会同步换算源入点，保持原来的归位画面。转场持续时间不额外增加工程长度。

## 工程与导出

- 工程格式为 `schemaVersion: 31`，可读 v1–v30。新镜头带 `shotcraft.version: 1`、`holdUs`、`regions`、`transition`（类型、时长及前一片段 ID）。读入时用 Zod 严格验证版本、区域边界、数量、时长和转场名。
- `sourceOffsetUs + localUs × speed` 决定源时钟；外部 30 fps 动作采样由同一纯函数换算。图片通过工程素材 ID 引用，会话 URL 不写入工程。
- React 导出逐帧写入现有原生缓存，帧数为 `ceil(durationUs × fps / 1e6)`，符合原生校验。已落定的普通 React 动效只保留一张末帧在内存中并重复写盘；Shotcraft 捕获完整时长。取消与失败均沿用导出调用方的缓存清理。
- 图片、3D、光束、转场与整体变换已烘焙进全画布 PNG，FFmpeg 使用中性变换合成。后续栅格化跳过已有 `sequenceId` 的图层，避免重复生成文字图层。
- 浏览器提供编辑和预览；正式成片导出仍使用桌面端的本地素材与 FFmpeg。磁盘缓存继续受已有 8 GB / 镜头限制约束。

首轮保留 `.bveffect` 导入导出能力。六种镜头内置于代码注册表，工程保存全部编辑参数；不支持把 React 实现打包成可执行动效包。AI 的镜头意图、截图区域识别、镜头排序、音乐拍点和音效编排尚未接入，新的六种镜头暂从 AI 字幕匹配候选中排除。

## 本轮验证

- Node 22 下执行 `npm run typecheck`、`npm test`、`npm run build`，全部通过；78 个测试文件、653 个测试。构建仍提示部分分块超过 500 KB。
- 使用真实编辑器截图和虚构工程文案，在 Chrome 中通过正式 React 渲染入口逐帧写出，再用本地 FFmpeg 编码：960 × 540、30 fps、895 帧、约 29.83 秒，覆盖六种镜头和两种转场；样片不含音频。
- 检查 16:9、9:16、1:1 的 18 组预览/导出画面，并检查深浅主题与较矮窗口。独立终检复核了聚光主体的投影边界与归位后 15 帧静止。
- 尚未完成 Tauri WebKit、原生 IPC 到 FFmpeg 的完整桌面导出实测，也未验证 Windows/Linux；浏览器验证不能替代这些平台验收。
