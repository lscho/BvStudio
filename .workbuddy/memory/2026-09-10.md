# 2026-09-10

## 只读分析：edge 服务新增桌面更新后端支持

**结论：客户端更新字段契约（权威来源 tauri-plugin-updater 2.10.1 src/updater.rs）**

- 请求：`GET /api/desktop-updates/latest?platform=<target>`；target ∈ windows-x86 / windows-arm / macos-x86 / macos-arm / linux-x86。
- 版本比较在 Rust 侧完成（`release.version > current_version`），服务端只需返回「最新一条」，无需接收 current_version。
- 响应被反序列化为 `RemoteRelease`（`#[serde(untagged)]`）。本项目的端点模板只有 `{{target}}`，应使用 **Dynamic 格式**（顶层平铺 `url` + `signature`），而非 Static 的 `platforms` map。
- Rust 必需（缺失即整个响应反序列化失败）：`version`（SemVer，`parse_version` 会 trim 前导 `v`）、`url`（必须能被 `url::Url` 解析）、`signature`（非空）。
- Rust 可选：`notes`（→ `Update.body`）、`pub_date`（**必须 RFC3339 且带时区**，否则整个响应失败）。
- 仅供前端 UI 层 `src/services/updaterModel.ts#parseDesktopUpdateInfo` 使用（走 `rawJson`，Rust 不校验）：`fileName`（回退 URL basename）、`fileSize`（安全正整数）、`isForceUpdate`（严格布尔 `true`）。
- 状态码语义：204 = 无更新（正常），400 = platform 非法，503 = 选中记录元数据不完整。注意 Tauri 对非 2xx 只 log 后 `ReleaseNotFound`，客户端会静默回到 idle，不会崩。
- 响应头必须 `Cache-Control: no-store`；现有 `CORS_HEADERS` 只声明 POST/OPTIONS，需补 GET。

**现状缺口**

- `edge/` 仅实现 license：`index.js` 单入口 → `handleLicenseRequest`（`edge/license-server.mjs`），路由 switch 只有 `POST /api/license/verify|redeem`。
- `src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints` 为空数组；`TAURI_UPDATER_ENDPOINT` 为 GitHub 仓库变量，由 `scripts/write-tauri-release-config.mjs` 写入临时 release config（要求含 `{{target}}` 且 https）。
- `docs/updater-api.md` 头部明确写「本仓库不实现也不部署外部更新服务」——本次要改。
- `desktop-release-manifest.json`（`scripts/build-desktop-release-manifest.mjs`）**不含** `notes` 与 `isForceUpdate`，字段为 schemaVersion/version/tag/generatedAt/repository/commitSha/platforms[{platform, installer, updater{fileName,fileSize,sha256,sourceUrl,signatureFileName,signature}}]；`sourceUrl` 仅在 `PUBLISH_GITHUB_RELEASE=true`（tag 推送）时非空。
- 既有可复用资产：`edge/license-core.mjs`（纯逻辑 + 测试）、`scripts/import-license-cards.mjs` 导出的 `loadSavedEsaCredentials` / `resolveNamespace`、`scripts/clear-kv.mjs` 的 ESA OpenAPI 客户端写法。
- 测试运行方式：`edge/**/*.test.{ts,mjs}` 由 vitest 收集（见 `vitest.config.ts`），**不是** `npm run test:release`（后者只跑 `scripts/*.test.mjs`）。edge 现有 31 个用例通过。
